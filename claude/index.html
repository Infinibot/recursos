Hazlo tú en 4 pasos

No hace falta saber programar, pero sí instalar un par de cosas una sola vez.

  1. 1
    Instala lo necesarioClaude Code, Node.js 22 o superior, FFmpeg y Python 3.
    Mac: brew install node ffmpeg python
    Windows: winget install OpenJS.NodeJS.LTS y winget install Gyan.FFmpeg (reinicia la terminal).
  2. 2
    Abre Claude Code en una carpeta vacíaCrea una carpeta nueva, entra en ella desde la terminal y escribe claude. Pega el prompt de abajo.
  3. 3
    Aprueba el guionClaude te enseña una tabla con las 7 láminas y espera. Cambia lo que no te guste y di «OK» cuando esté bien.
  4. 4
    Revisa las láminasTe enseña fotogramas de cada una. Pide correcciones concretas («la lámina 4 se lee muy rápido») y al final te deja lamina_1.mp4 … lamina_7.mp4.

Se rellena solo con lo que escribes arriba. Si cambias un dato, vuelve a copiarlo.

No sale idéntico a la primera. Es normal iterar: pide correcciones concretas lámina a lámina («más grande el titular», «el gráfico no se entiende»). Cuanto más preciso seas, menos vueltas.

El resultado cambia según la herramienta y el momento: tu carrusel no será igual que el de la publicación.

Revisa textos y datos antes de publicar. Los datos de ejemplo son inventados y las cifras que Claude proponga pueden ser erróneas. La última palabra es tuya.
