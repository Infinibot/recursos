Recurso · ANATOMY

Una frase. Un dibujo que explica cómo funciona.

Esta cafetera la ha hecho la skill Anatomy de Claude a partir de una sola frase. Desliza el dedo por encima y mira cómo prepara un espresso. Debajo, cómo instalarla y prompts para empezar.

DEMO · DATOS FICTICIOS · el tiempo va acelerado: un espresso real tarda unos 28 segundos.

Instálala en 3 pasos

Anatomy es una skill de código abierto (licencia MIT). Funciona dentro de Claude Code, la herramienta de Claude para el ordenador, y necesita tener Node.js instalado.

  1. 1
    Abre la terminal y pega esta líneaInstala la skill en tu Claude Code, para todos tus proyectos.
  2. 2
    Abre Claude CodeEn la carpeta donde quieras guardar el dibujo.
  3. 3
    Escribe /anatomy y tu frasePor ejemplo, uno de los prompts de más abajo. Claude trabaja solo y te deja una página que abres en el navegador.
Instalación
npx skills add wheresryan22/anatomy -g -a claude-code

Prompts para empezar

Cambia solo lo que va entre corchetes. Escríbelos en Claude Code, empezando por /anatomy.

1 · La cafetera de la demo
/anatomy explica cómo funciona por dentro una cafetera de espresso, interactivo. Guárdalo como una página HTML que se abra en el navegador y con los textos en español.
2 · Tu producto
/anatomy explica cómo funciona por dentro [tu producto: por ejemplo una máquina de coser, una bicicleta eléctrica, un horno de pan], interactivo. Que se pueda mover con el ratón y separar por piezas para ver cada una, con textos cortos en español y pocas piezas bien explicadas.
3 · Para un cliente que no sabe del tema
/anatomy dibuja cómo funciona [mi producto] para explicárselo a un cliente que no sabe nada de [el tema]. Tono claro, sin tecnicismos, textos cortos en español. Dime qué has simplificado.
4 · Para ponerlo en tu web
Ahora ponlo en una sola página HTML que pueda copiar a mi web, con un título arriba y dos líneas de texto debajo. Explícame en tres pasos cómo subirla.
5 · Para revisar lo que ha hecho
Repasa la figura que acabas de hacer: ¿qué piezas o datos has inventado o simplificado? Dame una lista de lo que debo comprobar yo antes de enseñársela a un cliente.
  • Mejor con objetos físicos. La skill está pensada para convertir una idea en una máquina o un instrumento. Con cosas que se tocan funciona mejor que con listas o diagramas de flujo.
  • Tarda un rato. Una figura sencilla puede llevarle a Claude desde varios minutos hasta cerca de una hora, según lo complicada que sea. Déjalo trabajar.
  • Pídele que se pueda abrir. Si quieres verlo pieza a pieza, díselo en la frase: «que se pueda separar por piezas».
  • Pocas piezas, textos cortos. Cuanto más concreto seas con lo que quieres enseñar, mejor sale.

Revísalo antes de enseñarlo a un cliente. Es un dibujo hecho por IA: puede simplificar o inventar piezas. Comprueba que lo que cuenta es correcto para tu producto. Usa el prompt 5 para que Claude te diga qué debes mirar.
