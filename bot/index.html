Prompt completo
Actúa como desarrollador senior de integraciones con la WhatsApp Business Platform.

Quiero que construyas un proyecto Node.js para un chatbot de atención al cliente.

DATOS:
Negocio: [NOMBRE_NEGOCIO]
Horario: [HORARIO]
Servicios: [SERVICIOS]
Información para contactar con una persona: [CONTACTO]

OBJETIVO:
Recibir mensajes de WhatsApp mediante la API oficial de Meta y responder únicamente a preguntas frecuentes relacionadas con los datos proporcionados.

ENTREGA UN PROYECTO EJECUTABLE CON:

1. Servidor Node.js.
2. Endpoint GET para verificar el webhook.
3. Endpoint POST para recibir mensajes.
4. Verificación de firma X-Hub-Signature-256.
5. Integración para responder mediante WhatsApp Cloud API.
6. Archivo .env.example sin secretos.
7. Validación de datos y manejo de errores.
8. Reintentos controlados cuando correspondan.
9. Control básico de duplicados.
10. Límites para evitar respuestas repetidas.
11. Respuesta segura cuando no se conoce un dato.
12. Escalado a una persona cuando se solicita.
13. Pruebas automatizadas usando datos simulados.
14. README con instrucciones de ejecución y despliegue HTTPS.

REGLAS:
No inventes información del negocio.
No incluyas tokens reales.
No envíes mensajes a números reales.
No despliegues automáticamente.
No utilices endpoints privados de WhatsApp Web.
Utiliza la API oficial.
No envíes mensajes fuera de las condiciones permitidas por Meta.
Indica las limitaciones de la ventana de atención de 24 horas y cuándo se requieren plantillas aprobadas.

Genera todos los archivos del proyecto.

Después explica cómo configurarlo con una app de prueba de Meta, cómo probarlo localmente y qué revisar antes de producción.

No consideres terminada la integración hasta superar las pruebas, verificar los permisos y confirmar que el webhook funciona.

Aviso. Esta demo no envía ni recibe mensajes reales. La integración requiere credenciales, configuración, seguridad y cumplimiento de las condiciones de WhatsApp Business Platform. Pueden aplicarse costes.
