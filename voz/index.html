Prompt para tu anuncio
Actúa como diseñador profesional de motion graphics y desarrollador frontend.

Quiero crear una página HTML autónoma que presente un anuncio animado para mi negocio.

DATOS:
Tipo de negocio: [TIPO_NEGOCIO].
Nombre comercial: [NOMBRE_NEGOCIO].
Mensaje del anuncio: [MENSAJE].
Precio que quiero mostrar, si procede: [PRECIO].
Colores de marca: [COLORES].

OBJETIVO:
Crear un anuncio animado de entre seis y diez segundos dentro de una página web.

REQUISITOS:

1. Entrega un archivo index.html completo.
2. Incluye HTML, CSS y JavaScript en un único archivo.
3. No utilices dependencias externas.
4. Diseña un escenario vertical 9:16.
5. Construye un objeto SVG relacionado con mi negocio.
6. Anima las palabras y el objeto con una secuencia coherente.
7. Utiliza movimientos elegantes, máscaras y transformaciones.
8. Añade botones funcionales REPRODUCIR y REINICIAR.
9. Permite cambiar el mensaje desde un campo editable.
10. No inventes precios, descuentos ni promesas comerciales.
11. Si falta información, deja un marcador editable claramente identificado.
12. Incluye diseño responsive y accesibilidad por teclado.
13. Respeta prefers-reduced-motion.
14. Haz que funcione sin internet.
15. No simules funcionalidades que no estén implementadas.

RESULTADO:
Devuélveme un archivo HTML funcional, no una explicación ni un storyboard.

Verifica que todos los botones funcionan y que modificar el mensaje cambia realmente la animación.

Antes de publicar, revisa precios, ortografía, derechos de imágenes y afirmaciones comerciales. La IA hace el anuncio en minutos, pero lo que dice es responsabilidad tuya.
